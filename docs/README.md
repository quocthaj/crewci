# Tài liệu CrewCI

Đặt PRD (xuất từ Claude Doc sang Markdown) vào đây, ví dụ `docs/prd.md`.

- `docs/adr/`: mỗi quyết định thiết kế lớn là một file ADR (mẫu: `0000-template.md`).
- ADR đầu tiên nên viết: lý do tự xây thay vì dùng framework agent có sẵn.
- ADR thứ hai: đặt LLMClient và CodingAgent sau interface.
